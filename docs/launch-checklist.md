# YouTube Channel Launch Checklist

A step-by-step guide to actually creating and launching the channel. Check items
off as you go.

## Phase 1 — Create the channel (the part only you can do)

> This happens on youtube.com with your Google account — it can't be scripted.

- [ ] Sign in to [youtube.com](https://www.youtube.com) with the Google account you
      want to use (consider a dedicated account, not personal).
- [ ] Click your profile picture → **Create a channel**.
- [ ] Choose a **name** and **handle** (`@yourhandle`). Handles must be unique.
- [ ] For a brand you may want a **Brand Account** channel (lets you add managers and
      separate it from your personal Google identity): go to
      [youtube.com/channel_switcher](https://www.youtube.com/channel_switcher) →
      **Create a channel**.
- [ ] Verify your account (phone number) to unlock custom thumbnails, longer videos,
      and live streaming: [youtube.com/verify](https://www.youtube.com/verify).

## Phase 2 — Brand the channel

- [ ] Upload a **profile picture** (800×800 recommended).
- [ ] Upload a **banner** (2560×1440; keep key content in the 1546×423 safe area).
- [ ] Write the **channel description** (About section) with keywords.
- [ ] Add **links** (website, socials) — these appear on your banner.
- [ ] Set a **channel trailer** for non-subscribers and a **featured video** for
      returning viewers.

## Phase 3 — Channel settings

- [ ] Set your **default upload settings** (visibility, category, license) in
      YouTube Studio → Settings → Upload defaults.
- [ ] Choose your **country** and **keywords** (Settings → Channel).
- [ ] Enable features you'll need (Studio → Settings → Channel → Feature eligibility):
      custom thumbnails, monetization eligibility, live streaming.
- [ ] Decide on **"Made for Kids"** status (required by COPPA).

## Phase 4 — First content

- [ ] Film and edit your **first 3–5 videos** before launch (a small backlog keeps
      momentum).
- [ ] Design a reusable **thumbnail template**.
- [ ] Write **titles, descriptions, and tags** (see the automation script for a
      repeatable metadata workflow).
- [ ] Create at least one **playlist** to organize content.

## Phase 5 — Go live & promote

- [ ] Publish the channel trailer.
- [ ] Publish your first video.
- [ ] Share on your other platforms (see [channel-plan.md](./channel-plan.md)).
- [ ] Post a Community/Shorts teaser.

## Phase 6 — (Optional) Set up API automation

If you want to automate uploads with the script in [`../automation`](../automation):

- [ ] Create a project in the [Google Cloud Console](https://console.cloud.google.com).
- [ ] Enable the **YouTube Data API v3**.
- [ ] Create **OAuth 2.0 credentials** (Desktop app) and download `client_secret.json`.
- [ ] Follow [`../automation/README.md`](../automation/README.md) to authenticate and
      upload.

## Ongoing

- [ ] Reply to comments in the first hours after publishing.
- [ ] Review Analytics weekly (CTR, retention, traffic sources).
- [ ] Iterate on thumbnails/titles for underperforming videos.
